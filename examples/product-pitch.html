commit-guard

Stop a secret before it ships

"The commit that leaks a key is always the one nobody meant to make."

What it checks

11

Known secret shapes scanned in the staged diff, before the commit ever runs

How it works

A real gate, not a nudge

  • Scans the staged diff before the commit executes - a match denies it outright
  • Nothing reaches git, nothing reaches a remote
  • Fails open on its own errors - never the reason a commit stops working

Get started

One line to install

/plugin install commit-guard --marketplace thisismairaj/commit-guard
