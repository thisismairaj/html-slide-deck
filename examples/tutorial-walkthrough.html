How Claude Code dev-mods hot-reload

A quick walkthrough

The basics

A mod is three files

  • .claude-plugin/plugin.json - the manifest
  • hooks/hooks.json - names the hooks module
  • The hooks module itself, exporting register(on)

The actual trick

Hot reload

While developing

Save the file, it reloads mid-session

  • The engine watches the mod's folder the whole time you're building it
  • Saving reloads the hooks module in a fresh environment
  • No restart, no build step for a TypeScript/JSX module

Timing

When it actually reloads

Save made duringReloads
Claude's own turn (editing the mod)When the turn ends, or sooner if a registered tool/command is about to run
Anywhere elseOnce the folder's been quiet for a moment

Before it ships

Validate, then share

  • claude plugin validate . checks the manifest and hooks the way the engine will
  • Sharing is one file away - a marketplace.json beside plugin.json
  • Then: /plugin install <name> --marketplace <owner>/<repo>
